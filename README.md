# Risk Weight Simulator

Interactive simulator for Maximilian Jager and Karl Schulz, *Nonlinear Bank Capital Regulation* (2026).

- Website: https://riskweights.github.io/
- Paper: https://drive.google.com/file/d/1gWIlKs8f74dNEKbL3XkxwxFksfOj9e98/view

The simulator shows how alternative risk weights for corporate loans, including the proposed U.S. 65%/100% schedule, affect bank equity, credit, the bailout probability and welfare, relative to the current Basel III IRBA risk weights. It is calibrated to German corporate lending. All computations run in the visitor's browser.

Fonts: STIX Two Text and Source Sans 3, SIL Open Font License 1.1 (folder `fonts`).
